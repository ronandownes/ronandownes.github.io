# ronandownes.github.io

Personal website and working project portfolio for Ronan Downes.

## Working principle

Each project should keep four things separate:

- **Original data** — preserved unchanged.
- **Processing** — reproducible code or documented transformations.
- **Analysis** — tables, visuals and quantitative findings.
- **Publication** — a clear webpage explaining the question, method, evidence and next steps.

## First project

**Home Energy Analytics** — half-hourly smart-meter electricity data, tariff-band analysis, high-load event detection, weather comparison and household energy experiments.

The site is intended to be a working example. Erik's projects should use his own repository, data management and analysis rather than copying finished outputs.
